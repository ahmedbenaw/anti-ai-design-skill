# Code-level patterns in AI-generated UI

Research date: 2026-08-28. Method: located repos with **verifiable in-repo provenance** (README project URLs, generator config files, sync artifacts), cloned them, and ran regex scans over source files (`*.tsx *.jsx *.ts *.js *.html *.css`, excluding `node_modules`, lockfiles, `.git`). Counts below are measured, not assumed. Two secondary sources were fetched only to cross-check claims, never counted as samples.

**Headline finding:** the folk wisdom ("indigo-600 everywhere", "purple→pink gradients") is partly stale. Modern Lovable/v0 output is **shadcn-based and uses semantic tokens** (`bg-primary`, `text-muted-foreground`, `hsl(var(--...))`) instead of raw palette utilities — the raw-palette clichés survive mainly in **Bolt** and one-shot chat output. The strongest scanner signals today are *stack fingerprints* (shadcn dump + lucide + cn() + HSL token block) and *generator artifacts* (`lovable-tagger`, `/placeholder.svg?height=`, `replit.md`, bolt `config.json`), not any single color class.

## Pattern catalogue

Format — **Name** · regex signature(s) · category · count · confidence · false-positive (FP) risk & mitigation. Counts = samples containing ≥1 match, of 12 (occurrence totals in parentheses where telling).

### Tier 1 — generator artifacts (near-proof, project-level)

1. **Lovable tagger/scaffold** · `lovable-tagger|componentTagger` in `vite.config.ts`/`package.json`; README `lovable\.dev/projects/[0-9a-f-]{36}`; repo/dir name suffix `-[0-9a-f]{8}$`; `bun\.lockb` + `components.json` combo · provenance · 3/3 Lovable samples (2/3 tagger, 1/3 README URL, 1/3 name suffix) · **high** · FP ≈ zero — the package exists only for Lovable. Scanner: any single hit = definitive.
2. **v0 placeholder URL** · `/placeholder\.svg\?height=\d+&width=\d+` (also bare `placeholder.svg` + `placeholder-user.jpg`) · provenance · 3/12 (V2, V4, and notably L1 — Lovable emits it too) · **high** · FP near zero; humans use picsum/unsplash. Definitive of AI scaffold, mostly v0.
3. **v0 sync README** · `Automatically synced with your \[?v0` and `Built with \[v0\]` · provenance · 0/12 in these clones (owners had rewritten READMEs) but documented as v0's default sync README in v0 docs/community · **medium** (verified mechanism, not observed in sample) · FP zero.
4. **Bolt template config** · file `config.json` at repo root matching `"template":\s*"bolt-` · provenance · 1/1 applicable Bolt React sample · **high** · FP zero.
5. **Replit Agent files** · presence of `replit.md` (Agent's memory file) and `.replit` · provenance · 1/1 Replit sample · **high** · `.replit` alone = hosted on Replit; `replit.md` specifically = Agent-managed.
6. **Full shadcn/ui dump** · directory `components/ui/` (or `src/components/ui/`) with 30–50 stock files (`accordion.tsx`…`tooltip.tsx`), `components.json`, `lib/utils` with `cn\(` = `clsx` + `tailwind-merge` · scaffold · 6/12 (L1 L2 L3 V2 V3 V4); `cn(`/clsx/CVA usage 8/12 (185–562 occurrences each) · **high** for "AI-scaffolded", medium for "AI-written" — humans also run `npx shadcn add`. Mitigation: flag when the dump is complete-but-mostly-unimported, or co-occurs with Tier-1 artifacts.
7. **HSL/OKLCH design-token block** · `--primary:\s*[\d.]+ [\d.]+% [\d.]+%;`, `hsl\(var\(--`, `oklch\(` in `index.css`/`globals.css` `@layer base` · scaffold · 8/12 (23–52 occurrences each) · **high** as stack marker · FP: any hand-set-up shadcn project. Mitigation: only score when tokens are byte-identical to shadcn defaults (e.g. `--radius: 0.5rem`, default zinc/slate scales).

### Tier 2 — strong code-level tells (Tailwind class patterns)

8. **`text-muted-foreground` body text** · `text-muted-foreground` · color/typography · 8/12 (26–385 occ) · **high** · FP: all shadcn users. Mitigation: ratio test — AI output uses it as effectively the *only* secondary text color; also pairs with #6/#7.
9. **Gray body-text fallback** · `text-(gray|slate)-(500|600)` · color · 9/12 (up to 422 occ in L2) · **medium** · very common in human Tailwind too; only score at high density or with Tier-1/2 co-occurrence.
10. **lucide-react icons** · `from ['"]lucide-react['"]`; icon names `\b(Sparkles|Zap|Shield|Rocket|ArrowRight|CheckCircle)\b` · iconography · lucide 9/12; those icon names 8/12; `ArrowRight` alone 7/12 · **high** as stack marker · FP: lucide is genuinely popular. Mitigation: require the cliché subset (Sparkles+Zap+Shield in one file = feature-grid smell) or `ArrowRight` inside a CTA button.
11. **shadow-heavy cards** · `shadow-(lg|xl|2xl)` · surface · 10/12 · **medium** · ubiquitous in human code; density signal only (≥8 per page).
12. **`min-h-screen` section wrapper** · `min-h-screen` · layout · 8/12 (16–36 occ in L2/B2/C1) · **medium** · humans use it once on root; AI repeats it per section/page. Mitigation: count>3.
13. **backdrop-blur glass** · `backdrop-blur(-(sm|md|lg|xl))?` · surface · 8/12 (18 occ in Claude heroes) · **medium-high** · FP: fashionable in human code 2023+. Score higher when combined with #14.
14. **White-alpha glass borders** · `bg-white/(5|10|20)` near `border-white/(10|20|30)` · surface · 3/12 but 27 occ in Claude sample — a **Claude/dark-hero tell** specifically · **medium** · Mitigation: require co-occurrence with dark hero (#15) + backdrop-blur.
15. **Dark hero background** · `bg-(gray-900|slate-900|slate-950|zinc-950|black)` on hero/body · color · 9/12 (23–25 occ in R1/C1) · **medium** · dark sites are legit; combine with glass/glow patterns.
16. **3-column feature grid** · `grid[^"]*(md|lg):grid-cols-3` (usually with `gap-8`) · layout · 8/12; `gap-8` 5/12 · **medium-high** · Tailwind-docs-canonical, humans use it too; scanner should require icon+title+paragraph card children (AST/DOM check) or co-occurrence.
17. **Hero type ramp** · `text-(4|5)xl[^"]*(sm|md|lg):text-(5|6|7)xl` · typography · 6/12 · **medium-high** · straight from Tailwind UI heroes; strong when + `font-bold` + `tracking-tight` (5/12).
18. **hover:scale-105 + transition** · `hover:scale-105`, `transition(-all)? duration-(200|300)` · motion · 6/12 each · **medium** · common human microinteraction; density signal.
19. **animate-pulse decorations** · `animate-pulse` on decorative divs (not skeletons) · motion · 7/12 · **medium** · FP: legitimate skeleton loaders — exclude matches inside components named Skeleton/Loading.
20. **blur-3xl background blobs** · `blur-3xl`, `blur-\[1\d\dpx\]`, typically `absolute.*rounded-full.*(bg|from)-.*blur-3xl` · decoration · 3/12 · **high specificity when present** · rare in hand-made sites; low FP. Low sample prevalence → weight as bonus, not core.
21. **Gradient headline text** · `bg-clip-text[^"]*text-transparent` (any order, usually with `bg-gradient-to-r`) · typography · 4/12 · **high specificity** · humans rarely; FP mainly landing-page templates. 
22. **Two-hue gradient washes** · `bg-gradient-to-(r|br|b) from-\w+-\d+ (via-\w+-\d+ )?to-\w+-\d+` · color · 3/12 samples but massive where present (B2: 133 occ; top pairs `from-blue-600 to-green-600` ×21, `from-red-600 to-pink-600` ×10) · **medium-high** · The hues track the site's theme — **not** reliably purple→pink. Scanner: count distinct gradient pairs; ≥5 distinct two-hue washes on one site is a strong tell.
23. **Tailwind-UI container triplet** · `max-w-7xl mx-auto` and `px-4 sm:px-6 lg:px-8` · layout · **1/12 each** (only L2) · **low prevalence, high specificity** — this is a Tailwind-UI-corpus fossil; modern shadcn output uses `container mx-auto` (3/12) or token containers instead. Keep as minor signal.
24. **space-y rhythm** · `space-y-(4|6|8)` · layout · 7/12 · **low** as signal (ubiquitous). Use only in co-occurrence scoring.
25. **`flex items-center justify-between` navbars** · literal string · layout · 6/12 · **low** (canonical Tailwind for any navbar).

### Tier 3 — copy & content tells

26. **Twin CTAs** · `>(Get Started|Start Free[^<]*)<` plus `>(Learn More|Learn more)<` in sibling buttons · copy · Get Started 3/12, Learn More 4/12, both 2/12 · **medium** · FP: real marketing sites use these too; require both in one hero.
27. **Placeholder people/testimonials** · `John Doe|Jane Doe|Acme|Sarah (Johnson|Chen)|Alex Chen`; avatar hosts `i\.pravatar\.cc|randomuser\.me|placehold\.co|ui-avatars\.com|images\.unsplash\.com` · content · names 3/12; avatar/image placeholders 4/12 · **high specificity** in *shipped* sites (fine in mockups). Scanner context matters: on a production domain this is damning.
28. **Vanity stats** · `\b\d+[KkMm]?\+ (users|customers|downloads)|99\.9% uptime|10,000\+` · copy · **0/12 verbatim**; observed variant "Trusted by 40,000+ traders" / "Trusted by 9,000+ small trade desks" (C1) → better regex: `Trusted by [\d,]+[KkMm]?\+` · **medium** (folk claim over-specific; the "Trusted by N+" formula is the real tell) · FP: real companies state real stats; treat as weak signal alone.
29. **Footer boilerplate** · `©?\s*\d{4}[^<]{0,40}All rights reserved` · copy · 5/12 · **low** (humans write this constantly). Co-occurrence only.
30. **Section id/anchor set** · `id="(features|pricing|testimonials|faq)"` or `href="#(features|pricing|testimonials|faq)"` · structure · 4/12 · **medium** · require ≥3 of the set in one file.
31. **Emoji in UI copy** · `✨|🚀` in markup · copy · 1/12 in code (C1); common in READMEs (V2: "⚙️📊", L2: "🏃‍♂️") · **low-medium** · better as a README/commit-message signal (`🚀 Features`, emoji-bulleted feature lists) than a DOM signal.
32. **Inter via Google Fonts** · `fonts\.googleapis\.com[^"]*Inter|font-family:[^;]*["']Inter` · typography · 4/12 strict (L2 L3 R1 C1; C1 also Space Grotesk ×6, Instrument Serif ×6, Bricolage Grotesque ×6, JetBrains Mono ×3 — matching the "slop font stack" named by developersdigest) · **medium** · Inter is a defensible human choice; Space-Grotesk+Instrument-Serif *pairing* is a stronger 2025-era Claude/v0 tell.

### Patterns from the candidate list that did NOT verify

- **indigo-600 / violet-500 accents:** 0/12. The indigo-default claim (dev.to article) reflects 2023-era ChatGPT/Copilot output; every 2025+ sample uses semantic tokens or theme-appropriate hues. Keep `indigo-(500|600)` as a *legacy* low-weight signal only.
- **`from-purple-* to-pink-*`:** 0/12 in code. Gradient clichés are real (22) but hue-follows-topic. The purple→pink meme is mostly about AI *image* slop and older chat output.
- **rounded-2xl/3xl "everywhere":** only 4/12, low counts — shadcn's `rounded-lg`/`rounded-md` via `--radius` is the actual norm.
- **GPT-3-era output (G1) shares nothing with the modern stack:** plain CSS, `border-radius: 4-5px`, no Inter, no gradients. Tells are model-generation-specific; a scanner needs dated signature sets.

## Co-occurrence clusters

**The Lovable stack** (all 3 Lovable samples): Vite + React + TS · `lovable-tagger` in vite.config · `bun.lockb` · full shadcn `components/ui` dump + `components.json` · `cn()` 185–222× · HSL token block in `index.css` · `text-muted-foreground` · lucide-react · react-router + `pages/Index.tsx` + catch-all `pages/NotFound.tsx` (present in L1/L2/L3) · README beginning "Welcome to your Lovable project" (L1) or the lovable.dev/projects UUID URL. Repo name may carry an 8-hex suffix.

**The v0 stack** (V2 V3 V4): Next.js App Router + TS · full shadcn dump · `placeholder.svg?height=H&width=W` images · `cn()` 210×+ · HSL tokens in `app/globals.css` · lucide-react · `next.config.mjs` with images unoptimized · README often "Automatically synced with your v0.dev deployments". Note V1: when asked for plain HTML, v0 emitted **Bootstrap 5** (`navbar navbar-expand-lg`, `d-flex`, Bootstrap Icons `bi bi-*`) with 4× "Learn More" buttons — a distinct v0-plain-HTML signature.

**The Bolt stack** (B2; B1 for plain JS): Vite + React + TS + Tailwind, `config.json {"template":"bolt-vite-react-ts"}` · **no shadcn, no tokens** — raw palette utilities (blue 97, green 67, purple 40) · heavy `bg-gradient-to-r from-X-600 to-Y-600` washes (133) · `min-h-screen` per page (19) · lucide-react absent here but common in Bolt output generally · `hover:scale-105`+`transition` microinteractions.

**The Claude dark-hero stack** (C1, corroborated by R1): `bg-black`/`bg-zinc-950` + `min-h-screen` hero · `bg-white/10 border border-white/20` glass (27×) · `backdrop-blur` (18×) · blur-3xl glow blobs · font mix Inter / Space Grotesk / Instrument Serif / JetBrains Mono loaded from Google Fonts · badge-above-H1 with Sparkles icon · "Trusted by N+" stat line · framer-motion.

**The ChatGPT single-file stack** (from G1 + secondary sources; modern sample = gap): one `index.html`, `cdn.tailwindcss.com` script or inline `<style>`, Google-Fonts link, emoji-as-icons, all sections in one file. GPT-3-era version: plain CSS, small radii, no framework.

**The Replit Agent stack** (R1): `.replit` + `replit.md` · React+TS+Tailwind with shadcn-style HSL tokens · `text-muted-foreground` (80×) · lucide (32×) · theme-appropriate accent (cyan for an OSINT terminal).

## Framework notes

- **React/Next (dominant):** every generator defaults here; the scannable unit is the JSX `className` string, so all Tier-2 regexes work verbatim. shadcn semantic tokens mean color-based rules must also match `bg-primary|text-muted-foreground|hsl(var(--`.
- **Vue:** no verified generated sample obtained (gap). Expect identical Tailwind strings in `<template>`; scanner regexes transfer unchanged; shadcn-vue exists and would mimic cluster #6/#7.
- **Plain HTML:** two distinct modes observed — Tailwind-CDN single file (ChatGPT-style), and **Bootstrap 5** (v0's plain-HTML mode, V1: `navbar-expand-lg`, `bi bi-*` icons). A scanner keyed only to Tailwind misses the Bootstrap branch entirely.
- **React Native/Flutter:** not covered (no samples); class-string regexes don't apply — would need NativeWind class scanning or widget-tree heuristics. Marked as gap.

## Proposed scoring (draft)

Score a page/repo; flag "likely AI-generated" ≥ 8 points, "near-certain" ≥ 15 or any Tier-1 hit.

| Signal | Points | Rationale |
|---|---|---|
| Tier-1 artifact (lovable-tagger, placeholder.svg?height=, bolt config.json template, replit.md, v0 sync README) | 15 each | Measured FP ≈ 0; each is generator plumbing no human writes |
| Complete stock shadcn dump + default HSL token block byte-matching defaults | 6 | 8/12 prevalence, but human shadcn installs exist → below flag threshold alone |
| `bg-clip-text text-transparent` gradient headline | 4 | High specificity, 4/12; rare in hand-written code |
| ≥5 distinct two-hue `from-*-600 to-*-600` washes | 4 | B2 evidence; hue-agnostic version of the gradient cliché |
| Glass combo: dark bg + `bg-white/10` + `border-white/20` + `backdrop-blur` in one element | 4 | Claude-cluster tell; requires 3-way co-occurrence so FP low |
| `blur-3xl` absolute blob + `rounded-full` | 3 | 3/12 but near-zero FP |
| Sparkles/Zap/Shield/Rocket set (≥3 in one file) with 3-col grid | 3 | Feature-grid smell; single lucide import scores 0 |
| Hero ramp `text-5xl md:text-6xl` + `font-bold` + `tracking-tight` + twin CTAs Get Started/Learn More | 3 | Each part common; the full sandwich is the tell |
| `min-h-screen` count > 3 | 2 | AI repeats per-section; humans use once |
| `animate-pulse` outside skeletons; `hover:scale-105 transition` | 1 each | 6–7/12 but heavy human use |
| Placeholder people (John Doe/pravatar/randomuser) on a production domain | 4 | Context-dependent; in a repo/mockup score 1 |
| "Trusted by [N]+" stat + `©… All rights reserved` + section-id set {features,pricing,testimonials,faq} | 1 each, +2 if all three | Copy signals only work in aggregate |
| `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8` exact triplet | 1 | Tailwind-UI fossil; only 1/12 now |
| Legacy set: `bg-indigo-(500|600)` accent, `from-indigo-500 to-purple-600` | 1 | 0/12 in 2025+ samples; keep for older code only |
| Inter+Space Grotesk or Inter+Instrument Serif Google-Fonts pairing | 2 | 2025-era slop-font pairing (C1 + secondary source agreement) |

Key design rule from the data: **no Tier-2/3 signal should flag alone** — every one appears in some legitimate human Tailwind code; the measured discriminator is density and co-occurrence, while Tier-1 artifacts are individually conclusive.

## Gaps

1. **No verified modern ChatGPT (GPT-4/5) web sample** — only a GPT-3-era repo (G1). Modern single-file ChatGPT output is characterized here from secondary sources only.
2. **No Cursor or Copilot sample** — these are editor assistants; their output carries no scaffold artifacts, so provenance is rarely declared. Attribution may be impossible at code level; only Tier-2 style tells would apply.
3. **Claude sample is a curated showcase** (claude-directory), biased toward polished output; a vanilla "make me a landing page" Claude sample would better represent defaults. R1 partially compensates.
4. **No Vue, React Native, or Flutter samples.**
5. **Small N (12) and survivor bias** — repos pushed to GitHub skew toward users who kept the result; single-shot throwaway output (where clichés are likely strongest) is underrepresented.
6. **Deployed-site scanning untested** — patterns were verified in source; production bundles minify structure but preserve Tailwind class strings and copy, so Tier-2/3 regexes should transfer; Tier-1 artifacts (configs, READMEs) do not.
7. **Vanity-stat and purple-pink claims need larger-corpus re-testing** before being weighted higher; current data says the popular formulations are wrong in detail.
8. GitHub code-search API was unavailable in this environment (session-scoped token), so prevalence was measured within samples rather than across all of GitHub.
